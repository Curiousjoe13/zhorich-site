# 🎮 Список команд чата

#### 📋 Основные команды

| Команда                   | Описание                                                      |
| ------------------------- | ------------------------------------------------------------- |
| `!info`                   | [Правила канала](ссылка) и общая информация                   |
| `!сбор`                   | Список игр на голосовании с количеством баллов                |
| `!сбортоп`                | Топ-3 игр по количеству собранных баллов                      |
| `!pc`                     | Характеристики игрового ПК                                    |
| `!discord`                | Ссылка на Discord-сервер                                      |
| `!donate`/`!донат`        | Ссылка для поддержки канала                                   |
| `!song`/`!песня`          | Текущий играющий трек                                         |
| `!songs request [ссылка]` | Заказ музыки (только для OW/Marvel Rivals/творческих стримов) |
| `!steam`                  | Ссылка на Steam-профиль                                       |
| `!bt`                     | BattleTag для игр                                             |
| `!эльф [текст]`           | Конвертер латиницы в кириллицу                                |
| `!выпороть`               | Превентивное наказание для чата (мем)                         |
| `!D20`                    | Виртуальный 20-гранный кубик                                  |
| `!MarvelID`               | ID для Marvel Rivals                                          |
