# Правила заказа музыки

Музыку можно заказывать только на стримах по Overwatch, Marvel Rivals или во время "творческих" стримов с помощью Nightbot.
Заказ трека происходит через команду !songs request (ссылка на Youtube).

На стримах по синглплеерным играм эта опция отключена.

В таком случае музыку поставить можно только через Donation Alerts. Музыкальные клипы, заказанные через награду "Заказать видео на просмотр" отсматриваться не будут. Баллы будут возвращаться.

> [!NOTE] ВАЖНО
> Стример оставляет за собой право скипать музыку, которая ему не нравится. За песни и клипы с запретками можно получить бан.
> Внимательно отсматривайте контент, который заказываете. Отговорки в духе "я не знал" не принимаются.

Музыкальные клипы заказываются только через [Donation Alerts](https://www.donationalerts.com/r/zhorich).

#### Команды Nightbot

| Команда                            | Описание команды                 |
| ---------------------------------- | -------------------------------- |
| !songs request + ссылка на Youtube | заказ песни                      |
| !songs current                     | выводит текущую песню            |
| !songs list                        | выдает ссылку на очередь заказов |
| !songs playlist                    | выдает ссылку на плейлист канала |

# Правила заказа видео

На Twitch и VK Play Live у вас есть возможность заказать видео на просмотр, используя соответствующую награду за баллы.
Видео должно соответствовать следующим требованиям:

1. Продолжительность - не более 10 минут.
2. Это не музыкальный клип. Музыка заказывается по отдельным правилам через [Donation Alerts](https://www.donationalerts.com/r/zhorich) или команду !sr. Баллы за музыкальные клипы будут возвращаться.
3. Видео не должно содержать материалов, которые бы нарушали правила поведения платформы и действующее законодательство РФ;

> [!NOTE] ВАЖНО
> Стример оставляет за собой право не просматривать заказанный контент, если он по той или иной причине не хочет его смотреть.
